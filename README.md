## Deploy
### Vercel
1. Push to GitHub
2. Import in Vercel - Framework: Other - Build: none - Output: .
3. Deploy

### Netlify
1. Drag & Drop this folder or connect GitHub
2. Build command: (empty) Publish directory: .

### GitHub Pages
1. Push to repo
2. Settings -> Pages -> Source: main branch / root
